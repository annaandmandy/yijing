# 六爻預測基礎 (Liu Yao Basics)

「六爻」是易經高階預測體系中的核心，強調「象數」與「數理」的嚴密推算。透過納入時間（月令、日辰）與五行生剋，能為具體事務提供極為精準的指引。

## 1. 六親的現代對意 (Six Relatives)
在六爻模式中，每一爻都會被賦予一個「六親」角色，代表不同的生活領域：
- **父母 (Parents/Education)**：代表學位、契約、房產、長輩、守護、文化、工作單位。
- **官鬼 (Career/Authority)**：代表事業、官位、官方、壓力、疾病、丈夫（女命）、困難。
- **妻財 (Wealth/Material)**：代表薪水、利潤、資產、物質、食物、妻子（男命）。
- **子孫 (Joy/Customer)**：代表才華、產品、客戶、快樂、解憂、技術、晚輩。
- **兄弟 (Competition/Partners)**：代表朋友、同事、競爭者、損耗金錢的人、幫手。

## 2. 世應關係 (Host & Objective)
- **世爻 (Shi)**：代表自己、當事人。世爻旺度代表自己的能量強弱。
- **應爻 (Ying)**：代表對方、目標物、競爭對手、所求之事。
- **分析**：若「應生世」代表事易成；若「應剋世」代表阻礙重重。

## 3. 空亡與伏藏 (Void & Hidden)
- **空亡 (Void)**：代表時機未到、虛假、或是暫時的力量缺失。雖然存在，但暫時不發揮作用。
- **伏藏 (Hidden)**：當卦中所需的「用神」沒有出現時，它可能隱藏在某個爻位之下。這代表事情的關鍵點隱藏在幕後，需要深入挖掘。

## 4. 六神 (Six Beasts)
六神依起卦日的日干排定，為卦象增加「神煞」色彩：
- **青龍**：喜慶、和諧、財富、正式。
- **朱雀**：文書、口舌、訊息、火災。
- **勾陳**：延遲、土地、勾連、陳舊。
- **螣蛇**：驚恐、奇怪、虛幻、糾纏。
- **白虎**：威猛、血光、速度、阻礙。
- **玄武**：曖昧、神祕、隱藏、失盜。
