# 梅花易數 (Plum Blossom Divination) 原理與計算

梅花易數是由宋代易學大師邵康節（邵雍）所創的一種高度靈活、不拘泥於儀軌的占卜方法。它以「數」為核心，認為宇宙萬物皆有數，透過數字的轉化即可推演事物的發展軌跡。

## 1. 基本成卦步驟

在本系統中，我們採用最經典的「三個數字」成卦法。

### 第一步：求取上卦
*   **方法**：將第一個數字除以 8，取其餘數。
*   **對應**：
    *   餘 1：乾 ☰
    *   餘 2：兌 ☱
    *   餘 3：離 ☲
    *   餘 4：震 ☳
    *   餘 5：巽 ☴
    *   餘 6：坎 ☵
    *   餘 7：艮 ☶
    *   餘 0 (或 8)：坤 ☷

### 第二步：求取下卦
*   **方法**：將第二個數字除以 8，取其餘數（規則同上）。

### 第三步：求取動爻
*   **方法**：將三個數字相加，除以 6，取其餘數。
*   **對應**：
    *   餘 1：初爻動
    *   餘 2：二爻動
    *   餘 3：三爻動
    *   餘 4：四爻動
    *   餘 5：五爻動
    *   餘 0 (或 6)：上爻動

---

## 2. 體用分析 (核心理論)

梅花易數最精華的部分在於「體用」關係的辯證。

### 什麼是「體」與「用」？
*   **體卦**：不包含「動爻」的那一個經卦。代表「我」、主體、現在的狀況。
*   **用卦**：包含「動爻」的那一個經卦。代表「他」、客體、外部環境、影響因素。

### 五行生剋判斷
我們根據體卦與用卦的五行屬性（金、木、水、火、土）來判斷吉凶：

1.  **用生體 (大吉)**：外部環境對主體有益，得助、事半功倍。
2.  **體用比和 (吉)**：兩者屬性相同，和諧穩定，順利前行。
3.  **體剋用 (小吉)**：主體能掌控局面，雖需費力但終有所獲。
4.  **體生用 (凶)**：主體能量洩漏，多勞少得，甚至有損失。
5.  **用剋體 (大凶)**：受外部嚴重制約或打擊，壓力極大，宜守不宜進。

---

## 3. 互卦與變卦 (進階應用)

*   **本卦**：事情的起點與現狀。
*   **互卦**：事情發展的中間過程（由本卦的二、三、四爻與三、四、五爻重新組合）。
*   **變卦**：事情的最終結局（本卦動爻變性後形成的卦象）。

# 十應與外應 (Ten Responses & External Omens)

梅花易數的精髓在於「心易」，即觀察占卜當下環境中的微妙變化作為斷卦補充。

## 1. 何謂外應
當您在思考、起卦或聽取問題時，周遭突然發生的現象。
- **聲響**：突然的雷聲、敲門聲、電話響。
- **動物**：喜鵲叫（主吉）、烏鴉鳴（主憂）、貓跳狗吠。
- **人物**：路人的爭吵、小孩的哭鬧、有人送禮物來。

## 2. 十應要領
1. **天時應**：天氣突變。
2. **地理應**：所在位置的方位意義。
3. **人事應**：旁人的言行。
4. **物像應**：器物的毀損或出現。
5. **顏色應**：映入眼簾的突發色彩。

## 3. 斷卦心法
外應不可過度牽強附會，須在「不期而遇」且「心有所動」時最為靈驗。

# 梅花易數進階取數法 (Advanced Calculations)

除了時間起卦，梅花易數強調「隨心所欲」，萬物皆可轉化為數。

## 1. 聲音起卦
聽到遠處傳來聲響，可以根據聲響的次數作為上卦，起卦的時間作為下卦。
- 例：敲門聲三下（離卦），加目前時辰數（如午時7），求得下卦。

## 2. 字數起卦
根據對方所寫文字的筆畫或字數起卦。
- **一字**：左半邊為上卦，右半邊為下卦。
- **兩字**：第一字為上卦，第二字為下卦。
- **多字**：總字數平分，奇數時前少後多。

## 3. 尺寸起卦
觀察器物的長短、高低，將尺寸轉化為卦。
- 凡長者為陽，短者為陰；或是直接以長度除以八取餘數。

## 4. 進階要領
「不動不占，無事不占」。唯有在「動覺」或「異常」發生時，取數起卦最為精準。
